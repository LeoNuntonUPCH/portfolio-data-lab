# Leonardo / Data Lab

Portafolio estático de Datos/ML, software e IoT. Cada proyecto enlaza a un repositorio para revisar su alcance, colaboración y evidencia. Las afirmaciones deben contrastarse con la fuente original.

## Desarrollo local

Abrir `index.html` en un navegador. No requiere instalación ni proceso de compilación.

## Publicación en Cloudflare Pages

Conectar este repositorio en Cloudflare Pages con el preset `None`, comando de build vacío y directorio de salida `/` (raíz del repositorio). La rama de producción es `main`.

## Privacidad

La página no incluye formularios, cookies propias ni scripts de analítica. Los enlaces externos abren GitHub.
